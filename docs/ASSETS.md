# 同梱素材の来歴と利用条件

- 観測ロボ: 2026-10-27にbuilt-in image_genで作成したオリジナルの架空デザイン。既存作品の人物・名称・ロゴを指定していません。原画と実際のpromptは `app/public/assets/demo/robot/`、加工と色除去の設定は `recipes/demo-robot.json`。同梱素材を使うための新しい画像生成は不要です。
- 共通ステーションのconsole、棚、植物、設備、壁の図柄、回るファン、DJ機器など: 元プロジェクトで生成・描画した汎用の設備。個別の第三者キャラクター・ジャケット・元サイトの画像は含めていません。Floor796は画風と密度の着想元であり、その配信画像を取り込んだテンプレートではありません。
- コードとこれらの同梱デモ素材はルートのMIT Licenseに従って再利用・改変・配布できます。新しく持ち込む参照画像やブランド素材は、その素材の利用条件を別途記録してください。第三者の権利をMITで再許諾するという意味ではありません。
- 加工processorのスナップショットと由来・hashは `tools/sprite-processor/source.json`。Pythonライブラリは `requirements-sprites.txt` で版を固定し、配布元のライセンスを維持します。画像生成サービスや外部検索の利用契約はこのキットに含まれません。

生成モデルの正確なbackend版・seedは取得できておらず、原画の再生成を画素単位で保証しません。採用した原画からの加工はrecipeで追試し、採用結果のPNG・JSON・来歴を一緒に保存します。
